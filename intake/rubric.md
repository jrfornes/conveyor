# Grading rubric

What earns Ready / Gaps / Unusable. The ticket-reviewer grades against these items; it does not invent a different scale.

## Items (every one is required for Ready)

- **Repro:** how to see the problem, or a concrete starting state.
- **Expected vs actual:** what should happen and what happens instead.
- **Numbered testable acceptance:** what must be true when done.
- **Scope:** in and out; no open-ended "etc."
- **Environment:** where it runs, versions, data that matter.

## Grades

- **Ready** — every item is present and testable. No gaps to list.
- **Gaps** — the problem is clear enough to rewrite; list every missing item, numbered, specific enough to fix in the ticket text.
- **Unusable** — the problem itself is missing. Cannot be rewritten without inventing the work.

Ready / Gaps / Unusable are the only legal grades. A / B / C are not used.
