# Stage 0 — Reconcile the handoff spec with the protocol

**Goal:** make `design_handoff_conveyor/CONVEYOR-UI-SPEC.md` safe to implement from.
**Ships:** documentation only. No behaviour change, no test change.
**Exit:** every path, directory and CLI verb named in the spec exists in the code, or is
explicitly marked as new work with a real target path.

## Why this stage exists

The handoff spec was written against an imagined filesystem. Building from it directly
would create a second, parallel queue layout alongside the real one. Per `CLAUDE.md`,
`docs/conveyor-handoff-protocol.md` is normative and wins on everything but scope.

## The preset model to write into the spec (§15.2)

```
conveyor.conf                       ACTIVE pipeline. Read by role loops + handoff.sh.
                                    Regenerated by "Make active" via config.save().
.conveyor/workflows/<slug>.json     Saved presets: { name, description, roles[], gate }
.conveyor/active                    "<slug>" — which preset conveyor.conf came from
```

"Make active" = read preset → `config.save(root, cfg)` → write `.conveyor/active`.
Refused while loops run (`cmd_pack` already enforces this; reuse the check and its copy).
